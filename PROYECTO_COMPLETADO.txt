================================================================================
  🚀 CÓMO EMPEZAR
================================================================================

PASO 1: Configurar Google Cloud (30-45 minutos)
  → Abre: docs/SETUP_GOOGLE_CLOUD.md
  → Sigue la guía paso a paso
  → Copia los IDs de carpetas y credenciales

PASO 2: Rellenar Variables de Entorno
  → Edita: .env.local
  → Rellena con los valores de Google Cloud
  → Copia también DATABASE_URL de PostgreSQL

PASO 3: Configurar Base de Datos
  ```bash
  npx prisma migrate dev --name init
  ```

PASO 4: Instalar Dependencias (si no está hecho)
  ```bash
  npm install
  ```

PASO 5: Iniciar Servidor de Desarrollo
  ```bash
  npm run dev
  ```
  → Abre: http://localhost:3000
  → Inicia sesión con Google

PASO 6: Probar Funcionalidades
  → Crear un trámite
  → Verificar que se creó la carpeta en Google Drive
  → Cambiar estado del trámite
  → Revisar historial

  🔑 VARIABLES DE ENTORNO NECESARIAS

GOOGLE_SERVICE_ACCOUNT_PRIVATE_KEY     - Clave privada JSON

================================================================================
  📊 ESQUEMA DE BASE DE DATOS
================================================================================

6 MODELOS PRISMA CREADOS:

1. Cliente
   - ID, nombre completo, fecha nacimiento
   - Nacionalidad, pasaporte, dirección
   - Email, teléfono, situación migratoria actual
   - Relación 1:N con Trámites

2. Tramite
   - ID, código único (TR-00234)
   - Relación con Cliente
   - Tipo de trámite, estado
   - Honorarios, forma de pago
   - ID carpeta Google Drive
   - Relaciones con Documentos y Historial

3. Documento
   - ID, nombre, tipo
   - ID archivo Google Drive
   - Origen (manual o automático)
   - Relación con Trámite

4. DocumentoGenerado
   - ID, nombre generado
   - ID archivo Google Drive
   - Relación con Trámite y Plantilla

5. Plantilla
   - ID, tipo (checklist/contrato)
   - Tipo de trámite que aplica
   - ID archivo Google Docs
   - Relación con DocumentosGenerados

6. HistorialEstado
   - ID, estado anterior y nuevo
   - Usuario, fecha, notas
   - Relación con Trámite

================================================================================
  📞 SOPORTE Y TROUBLESHOOTING
================================================================================

Si hay problemas:
  1. Revisa SETUP_INICIAL.md (sección Troubleshooting)
  2. Verifica que .env.local tiene todas las variables
  3. Comprueba que PostgreSQL está corriendo
  4. Lee docs/SETUP_GOOGLE_CLOUD.md si es error de Google

Errores Comunes:
  • "Service account credentials not configured"
    → Verifica GOOGLE_SERVICE_ACCOUNT_EMAIL y PRIVATE_KEY

  • "Cannot create folder in Drive"
    → Verifica DRIVE_FOLDER_CLIENTES_ID
    → Comprueba permisos de cuenta de servicio

  • "Cannot connect to database"
    → Verifica DATABASE_URL
    → Asegúrate que PostgreSQL está corriendo
