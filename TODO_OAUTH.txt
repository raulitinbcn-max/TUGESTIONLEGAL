🆘 TROUBLESHOOTING

  "Google credentials not configured"
    [ ] Verifica GOOGLE_CLIENT_ID en .env.local
    [ ] Verifica GOOGLE_CLIENT_SECRET en .env.local
    [ ] Reinicia: npm run dev

  "Cannot create folder in Drive"
    [ ] Verifica que copiaste IDs correctamente
    [ ] Verifica que DRIVE_FOLDER_CLIENTES_ID está rellenado
    [ ] Reinicia: npm run dev

  "Cannot connect to database"
    [ ] Verifica que PostgreSQL está corriendo
    [ ] Verifica DATABASE_URL en .env.local
    [ ] Reinicia: npm run dev

  Login redirige a error page
    [ ] Verifica que OAuth URIs incluyen:
        http://localhost:3000/api/auth/callback/google
    [ ] En Google Cloud → Credenciales → OAuth
    [ ] Agrégalo si falta
    [ ] Reinicia: npm run dev
